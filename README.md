# 🏔️ Focus: Nature Cams

A free browser extension that helps you stay focused. While focus mode is on, distracting sites
(Instagram, TikTok, X, Reddit…) open a random **live webcam of the sea, mountains or wild nature** instead —
and only from places where it's **daylight right now**.

**Website:** https://ra1ich.github.io/focus-cams/

## Features

- ⏱ Focus for 25 min, 50 min, 1.5 h or with no timer — one click on the toolbar icon
- ⚡ Instant interception: the distracting page never even starts loading
- ☀️ Daylight-aware: the sun's position is calculated for every cam, so no pitch-black beaches at night
- 🎲 40+ cams: Maldives, Bali, the Dolomites, Iceland, Tenerife, California, Kenya and more
- 🌌 Night cams (northern lights, volcano) appear only when it's dark there
- ✏️ Fully editable lists of sites and cams, including your own YouTube live streams
- 🔒 No accounts, no analytics, no servers — settings stay in your browser
- 🌍 English and Russian interface

## Install

1. Download **`focus-cams.zip`** from the [latest release](../../releases/latest) and unzip it.
2. Open `chrome://extensions` (Edge: `edge://extensions`).
3. Turn on **Developer mode**.
4. Click **Load unpacked** and select the `focus-cams` folder.
5. A welcome page will guide you through pinning the icon and a 1-minute demo.

Works in Chrome, Edge, Brave, Opera, Yandex Browser and other Chromium-based browsers.
